# QueryLite

**SQLite Database Browser for Android**

A powerful, dark-themed SQLite database management tool built with Jetpack Compose and Material Design 3.

## Features

- **Table Viewer** - Browse table data in an interactive data grid
- **SQL Query Runner** - Execute custom SQL with syntax highlighting and results display
- **CSV Import/Export** - Import data from CSV files and export tables to CSV
- **SQL Syntax Highlighting** - Color-coded SQL editor with keyword, string, and number highlighting
- **DB Diff Tools** - Compare two databases side by side to find added, removed, and changed rows
- **Open External DB Files** - Open .db, .sqlite, .sqlite3 files from any location
- **Query History** - Track all executed queries with favorites support
- **Schema Viewer** - View table schemas, column types, indexes, and constraints

## Tech Stack

- Kotlin 1.9.22, AGP 8.2.2, Gradle 8.5
- Jetpack Compose + Material Design 3 (Dark theme with amber accents)
- Room Database for query history and saved connections
- Min SDK 29, Target SDK 34, ARM64
