# Changelog

All notable changes to QueryLite will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Initial release
- Table viewer with interactive data grid
- SQL query runner with syntax highlighting
- CSV import/export functionality
- Database diff comparison tools
- External database file opening
- Query history tracking with favorites
- Schema viewer with column and index details
- Dark Material Design 3 theme with amber accents
- Room database for persistent storage
- Debug logging system
- GitHub Actions CI/CD for debug and release builds
